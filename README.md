# 🎵 Terminal Music Player

A lightweight, fully functional audio player developed entirely in **C** to run directly from the command line / terminal.

![C Standard](https://img.shields.io/badge/Language-C-blue.svg)
![Platform](https://img.shields.io/badge/Platform-Terminal%20%7C%20Console-lightgrey.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)

📌 Overview
This project is a console-based music player created as a school project to apply core C programming concepts, such as dynamic memory allocation, data structures (linked / doubly linked lists), and file handling / third-party audio libraries.

It allows users to load audio tracks, control playback in real-time via a text-based terminal menu, and manage playlists seamlessly.

✨ Features
⏯️ Playback Controls: Play, pause, stop, skip, and rewind tracks.

📜 Playlist Management: Load and seamlessly navigate through song queues.

🎚️ CLI Interface: Intuitive, menu-driven command line interface.

⚡ Lightweight & Fast: Minimal resource consumption thanks to native C execution.

🛠️ Tech Stack & Requirements
Language: C (C99 / C11 standard)

Compiler: gcc or clang
